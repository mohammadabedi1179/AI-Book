## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohammadabedi1179/AI-Book.git
cd AI-Book
```

### 2. Open the learning material

You can open the `.docx` and `.pptx` files directly with compatible office software.

For the computational material, open the corresponding `.ipynb` file using **Jupyter Notebook**, **JupyterLab**, **VS Code**, or another notebook-compatible environment.

### 3. Run the notebooks locally

If Jupyter is not already installed:

```bash
python -m pip install jupyter
```

Then launch:

```bash
jupyter notebook
```

or:

```bash
jupyter lab
```

Navigate to the desired chapter and open its notebook.

> **Note:** Individual notebooks may require additional Python packages. If a notebook reports a missing module, install the required package in the same Python environment before running the corresponding cells.

## 🎯 How to Use This Repository

A practical study workflow is:

1. **Start with the chapter document** to understand the theory and main concepts.
2. **Review the presentation slides** for a condensed visual summary.
3. **Work through the Jupyter notebook** and run the examples yourself.
4. **Modify parameters and code** instead of only executing the provided cells.
5. **Compare the computational results with the theoretical material** in the chapter notes.

The notebooks are most useful when treated as experiments rather than static examples.

## 🤝 Contributing

Contributions that improve the educational quality of the repository are welcome.

Useful contributions include:

* correcting errors or unclear explanations;
* improving notebook readability;
* adding comments and documentation;
* fixing broken or outdated code;
* adding useful examples or exercises;
* improving the organization of chapter material.

A typical contribution workflow is:

```bash
# Fork the repository first, then:
git clone https://github.com/<your-username>/AI-Book.git
cd AI-Book

git checkout -b improvement/my-change

# Make your changes

git add .
git commit -m "Improve chapter material"
git push origin improvement/my-change
```

Then open a **Pull Request** describing the changes.
